# Python Programming Internship Tasks — Datheon

This repository contains the four Python projects completed during my 4-week virtual **Python Programming Internship** with Datheon. These projects focus on core Python fundamentals, file system automation, data handling, and command-line application logic.
# 📂 Repository Contents

# 1. Stock Portfolio Performance Tracker
* **File:** `Stock Portfolio Performance Tracker`
* **Overview:** A Python tool designed to track stock holdings, calculate total investment values, and evaluate overall portfolio returns.
* **Key Concepts:** Data structures (dictionaries/lists), arithmetic calculations, and user input processing.

# 2. Automated File Organiser and Cleanup Utility
* **File:** `Automated File Organiser And Cleanup Utility`
* **Overview:** A utility script that scans a target directory and automatically sorts files into categorized folders based on their file extensions.
* **Key Concepts:** File system navigation (`os` / `shutil` modules), path handling, and automation scripting.

# 3. Rule-Based Interactive Terminal Assistant
* **File:** `Rule Based Interactive Terminal Assistant(Chatbot)`
* **Overview:** A command-line chatbot that responds to user queries using predefined rules, keyword matching, and conversational flow logic.
* **Key Concepts:** Conditional branching, string manipulation, and continuous loop handling.

# 4. Hangman Word Guessing Game
* **File:** `Hangman Word Guessing Game (Console)`
* **Overview:** An interactive terminal-based version of the classic word-guessing game featuring attempt tracking and input validation.
* **Key Concepts:** Game state management, loops, randomization (`random` module), and edge-case handling.

   cd Datheon-Tasks
   ```

   ```

3. **Run any script from the terminal:**
